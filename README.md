## What this fork adds

One thing: opening `magnet:` links from browsers, other apps or the share sheet, with automatic TMDB matching,
multi-language search and playback through the existing engine.

## Everything else

Documentation, install instructions, build steps, credits and support for the app itself all live upstream:

- **[Nuvio Enhanced](https://github.com/luqmanfadlli/NuvioMobile-Enhanced)** — the direct parent of this fork.
- **[Nuvio Mobile](https://github.com/NuvioMedia/NuvioMobile)** — the original app.
- **[nuvio.tv](https://nuvio.tv/support)** — supporting the upstream project.

APKs for this fork are published in [Releases](https://github.com/Narxib/NuvioMobile-Enhanced-Plus/releases/latest)
(debug-key signed, installs alongside the official app).
